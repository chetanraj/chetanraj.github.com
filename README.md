# chetanraj.github.com

Personal site source. GitHub Pages serves the production build from `master`. Source lives on `portfolio-react` and `main`.

## Scripts

- `npm run dev` — local Vite server
- `npm test` — Vitest
- `npm run build` — production build in `dist/`
- `npm run deploy` — build and publish `dist/` to the `master` branch (gh-pages)
